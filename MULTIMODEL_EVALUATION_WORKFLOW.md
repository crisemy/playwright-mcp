# AI QA Multi-Model Evaluation Workflow

- Prepare the baseline repository and verify that the Playwright + TypeScript framework is clean. -> Done!
- Create a baseline commit of the framework. -> Done!

-- Use the worktree capability from Github:

- Create an isolated environment for Model A. -> Done!
- Create an isolated environment for Model B. -> Done!
- Create an isolated environment for Model C. -> Done!
- Verify that all three models start from the exact same baseline. -> Done!
- Verify that AGENTS.md is present in all three environments. -> Done!
- Verify that all four Skills are present in all three environments. -> Done!
- Verify that skill-compliance-evaluation is available. -> Done!

-- Environments Configuration

- Configure Model A.
- Configure Model B.
- Configure Model C.

- Run authentication-exploration with Model A.
- Run authentication-exploration with Model B.
- Run authentication-exploration with Model C.
- Preserve the exploration results from each model.
- Compare the exploration results without modifying them.
- Run test-design with Model A.
- Run test-design with Model B.
- Run test-design with Model C.
- Preserve the test design results from each model.
- Compare the test designs without modifying them.
- Run playwright-test-generation with Model A.
- Run playwright-test-generation with Model B.
- Run playwright-test-generation with Model C.
- Preserve the generated artifacts from each model.
- Verify that no model modified the framework outside the allowed scope.
- Verify that each model used the existing framework architecture.
- Verify that each model created only the expected artifacts.
- Start Playwright MCP for Model A.
- Start Playwright MCP for Model B.
- Start Playwright MCP for Model C.
- Execute the tests generated by Model A.
- Execute the tests generated by Model B.
- Execute the tests generated by Model C.
- Preserve the execution results from each model.
- Separate execution status from compliance status.
- Run skill-compliance-evaluation on Model A.
- Run skill-compliance-evaluation on Model B.
- Run skill-compliance-evaluation on Model C.
- Preserve the compliance reports.
- Evaluate requirement coverage for each model.
- Evaluate traceability for each model.
- Evaluate assertion quality for each model.
- Evaluate behavioral correctness for each model.
- Evaluate framework architecture compliance for each model.
- Evaluate locator quality for each model.
- Evaluate determinism for each model.
- Evaluate unsupported assumptions for each model.
- Evaluate evidence fidelity for each model.
- Build the comparative scorecard.
- Compare the results across all three models.
- Identify differences between models.
- Identify compliance false positives.
- Identify compliance false negatives.
- Identify cases where tests pass but are incorrect.
- Identify cases where tests fail because of implementation problems.
- Identify potential evaluator weaknesses.
- Repeat the evaluation when significant disagreement occurs.
- Record the final experiment results.
- Preserve the original artifacts from all three models.
- Compare all models under equivalent conditions.
- Document conclusions and follow-up experiments.
